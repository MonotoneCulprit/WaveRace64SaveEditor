Wave Race 64 stores Forward 3 Lap & Best Lap Records as 6 byte sets.
Scores & Reverse Records are stored as 5 byte sets.

Forward 3 Lap & Best Lap Records are stored from 0x60-0x11F.
Scores are stored from 0x120-0x1A6.
Reverse Records are stored from 0x1D8-0x1FF.

3 Lap and Best Lap 6 Byte explanation:
Byte 1: Character data and Start of 3 byte integer for time.
The Character is represented as 00, 20, 40, or 60. 00 = Hayami, 20 = Mariner, 40 = Stewart, 60 = Jeter.
Bytes 1, 2, and 3: Integer representing the time in milliseconds. Subtract the Character data to get the correct integer (i.e 61 become 01).
Bytes 4 & 5: Custom initials or lack thereof.
Byte 6: Custom Craft Use. 00 is No. 01 is yes.


EXAMPLES:
The default Sunny Beach Forward 3 Lap Record is stored as 01 5F 90 73 9C 00.

01 = 00 = Hayami
01 5F 90 = 65536 24320 144 = 90000 milliseconds = 1:30.000
73 9C = 01110011 10011100 = 0 11100 11100 11100 = (No Custom Initials) - - -
00 = Default Craft Settings

My current Sunny Beach Forward 3 Lap Record is stored as 20 F9 B9 B7 83 00.

20 = Mariner
20 F9 B9 = 00 F9 B9 = 0 63744 185 = 63929 milliseconds = 1:03.929
B7 83 = 10110111 10000011 = 1 01101 11100 00011 = (Yes Custom Initials) M - C
